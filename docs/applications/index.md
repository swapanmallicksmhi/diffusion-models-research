# Applications in Earth-System Science

## Priority domains

### Numerical weather prediction

Investigate conditional analysis generation, multivariable atmospheric states, regional downscaling and probabilistic prediction.

### Satellite radiance assimilation

Study observation operators, nonlinear radiative transfer, all-sky retrieval uncertainty, instrument-specific quality control and information content.

### Ensemble uncertainty

Assess whether generated sample spread is calibrated and meteorologically meaningful using rank histograms, CRPS, spread–skill diagrams and out-of-sample verification.

### Useful evaluation table

| Dimension | Representative questions |
|---|---|
| Accuracy | RMSE, MAE, bias and spatial structures |
| Probabilistic reliability | CRPS, rank histograms, coverage |
| Physical consistency | Balance, cross-variable dependence |
| Generalization | Unseen dates, regions, regimes and sensors |
| DA impact | Observation departures and forecast skill |
